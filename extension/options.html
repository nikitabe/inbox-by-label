2. Choose how to count

Badges show unread / total inbox counts. Reading mail reduces the unread count; the total stays unchanged. Counts refresh every minute and when you return to Gmail. Use the sidebar refresh button after archiving for a quicker update.

3. Discover and arrange labels

Matches ignore capitalization and a leading •. Leave blank to include all your custom labels. New matching labels appear automatically on the next refresh.

Your labels

Uncheck a label to exclude it from this sidebar. Use the arrows to change its order. These settings do not change labels in Gmail.

The inbox sidebar appears above Gmail’s normal label list. All original label rows remain available so you can change their colors and other settings. To see archived mail for a label, remove in:inbox from Gmail's search field.

Access and privacy

Google's metadata permission can read labels and message headers, but cannot read message bodies or change mail. This extension requests only your account email, label names, and message/conversation IDs to calculate counts. Counts are saved locally in Chrome. There is no external server or analytics.

The Gmail page permission allows the extension to add the sidebar. It does not inspect email bodies. Disconnect clears its local data and Chrome token cache; to revoke Google's grant, remove Inbox by label from Google account connections.
